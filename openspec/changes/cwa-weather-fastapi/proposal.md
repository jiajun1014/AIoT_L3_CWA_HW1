# Proposal: CWA 天氣觀測預報 Web 應用程式

## 背景
在 AIoT 課程 L2/L3 中，學習從 AI Agent 與 Vibe Coding 出發，遵循「Prompt → Spec → Code → GitHub」的現代軟體開發思維。
本提案旨在建立一個結合中央氣象署（CWA）OpenData 與 FastAPI 框架的現代化氣象資訊網站，兼具實用工具與個人首頁展示功能。

## 範疇與功能
1. 串接 CWA F-C0032-001 預報資料。
2. 建立具備高容錯機制的後端 API 服務。
3. 打造支援多時段預報、區域過濾及關鍵字檢索的高顏值毛玻璃介面。
4. 提供靈活的 API Key 設定與離線展示支援。
