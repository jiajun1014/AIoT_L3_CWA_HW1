# Spec: CWA 氣象天氣 Web App (FastAPI + OpenData)

本規格定義基於台灣中央氣象署（CWA）開放資料之氣象資訊系統與個人首頁 Web 應用程式。

## 1. 系統目標與範圍
- **核心定位**：提供台灣 22 縣市之即時與今明 36 小時天氣預報查詢、舒適度評估與視覺化指標。
- **架構原則**：採用前後端分離結構，後端以 FastAPI 提供 RESTful API，前端以 HTML5/CSS3/JavaScript 實現動態毛玻璃視覺介面。
- **資料來源**：中央氣象署氣象資料開放平臺（API 代碼：`F-C0032-001` - 一般天氣預報-今明36小時天氣預報）。
- **容錯與彈性**：支援自訂 API 授權金鑰，並具備全台 22 縣市結構化備援快取（Fallback），確保離線或無金鑰環境仍能平穩運行。

## 2. 功能規格 (Functional Requirements)

### 2.1 氣象資料擷取與解析
- 系統須支援台灣 22 縣市的分區檢索（北部、中部、南部、東部、離島）。
- 每個縣市解析 5 項核心氣象要素：
  1. `Wx` (天氣現象與代碼，如：多雲時晴、陰短暫雨)
  2. `PoP` (降雨機率百分比 %)
  3. `MinT` (最低溫度 °C)
  4. `MaxT` (最高溫度 °C)
  5. `CI` (舒適度指標描述，如：舒適、稍有寒意、悶熱)
- 36 小時預報時段切換：
  - 時段一：今天白天 / 今晚至明晨
  - 時段二：明天白天
  - 時段三：明天晚上

### 2.2 後端 API 規格 (API Contracts)
- `GET /api/weather/forecast`:
  - Query 參數：
    - `city` (string, optional): 指定縣市名稱（如：臺北市、高雄市）。若未提供則回傳全台 22 縣市。
  - Header 參數：
    - `X-CWA-API-KEY` (string, optional): 中央氣象署 Authorization Key。
  - 回傳格式：
    ```json
    {
      "status": "success",
      "source": "cwa_live" | "fallback_cache",
      "updated_at": "2026-09-23T10:45:00",
      "data": [
        {
          "city": "臺北市",
          "region": "north",
          "periods": [
            {
              "start_time": "2026-09-23 12:00",
              "end_time": "2026-09-23 18:00",
              "wx": "多雲短暫陣雨",
              "wx_code": "8",
              "pop": "30%",
              "min_t": "24",
              "max_t": "31",
              "ci": "舒適至悶熱"
            }
          ]
        }
      ]
    }
    ```
- `GET /api/health`:
  - 回傳伺服器運作狀態、Python 版本、以及 API Key 配置情況。

### 2.3 前端使用者體驗
- **設計風格**：深邃藍紫與活力亮彩、毛玻璃漸層效果（Glassmorphism）、微動畫響應。
- **即時篩選**：支援全區與分區頁籤（全台、北部、中部、南部、東部、離島）與城市關鍵字模糊搜尋。
- **個人介紹與課程展示**：整合開發者資訊、AIoT 課程標記、SDD 規格展示。
- **金鑰動態配置**：提供前端設定 Modal，支援將使用者個人氣象署授權碼暫存於瀏覽器，無痛發起即時請求。
